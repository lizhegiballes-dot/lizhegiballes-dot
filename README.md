## Featured

### [German Learning Assistant](https://github.com/lizhegiballes-dot/german-learning-assistant)

**Select a word. Keep your flow.**

A local-first Chrome companion for German reading: quick word lookup, daily collections, personal notes, review and one-click Anki / CSV exports. English-first, with a Chinese interface option.

[Download](https://github.com/lizhegiballes-dot/german-learning-assistant/releases/latest) · [Get started](https://github.com/lizhegiballes-dot/german-learning-assistant#readme)
